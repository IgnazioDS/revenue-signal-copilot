# Roadmap

## Phase 1

- Ship local CSV ingestion with a typed signal schema
- Score accounts with transparent factors and recency decay
- Generate account briefs and outreach angles from the score trace
- Add real CRM and website-data integrations
- Track conversion feedback to refine scoring

## Phase 2

- Add production integrations for the target users.
- Introduce persistence and operational telemetry.
- Expose a service layer beyond the local CLI.

## Phase 3

- Harden deployment story.
- Add richer validation and failure handling.
- Publish sample data and demos.
